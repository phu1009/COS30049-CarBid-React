# CarBid – Vehicle Auction Web App (React + Vite)

Group 5 project for **COS30049 Computing Technology Innovation Project** at Swinburne University of Technology (Hanoi), Semester 2 2024.

CarBid is the front-end prototype of an online auction platform for cars and motorbikes. It was designed together with the [Project Design Report](docs/Project%20Design%20Report.pdf), which covers requirements, system architecture and UI design.

## Pages / components
| Component | Purpose |
| --- | --- |
| `Dashboard.jsx` | Overview of live auctions and featured vehicles |
| `Listing.jsx` | Browse vehicles listed for auction |
| `Bid.jsx` | Place bids on a selected vehicle |
| `Deal.jsx` | Deals the user has won or is negotiating |
| `Tracking.jsx` | Track the status of purchased vehicles |
| `Statistics.jsx` | Bidding / sales statistics |
| `Settings.jsx` | Account and profile settings |
| `Sidebar.jsx` | App navigation |

## Tech stack
React 18 · Vite · CSS · ESLint

## Run
```bash
npm install
npm run dev
```
